# Introduction to Artificial Intelligence: Final Project

A team project by Yuval Nerson and Natan Lerner for the Introduction to Artificial Intelligence course at Bar-Ilan University. The notebooks compare supervised-learning approaches across regression and image-classification tasks.

## Project components

| Part | Task | Methods and focus |
|---|---|---|
| I | Auto MPG regression | Exploratory analysis; linear, polynomial, and k-Nearest Neighbors regression |
| II | CIFAR-10 classification | Logistic regression, SVM, and k-Nearest Neighbors |
| III | Neural-network classification | PyTorch classifier, architecture choices, and hyperparameter optimization |
| IV — Bonus | Auto MPG regression with a neural network | PyTorch DNN adapted from the classification model |

## Notebooks

- [Part I — Auto MPG regression](./Part_I_Regression_Task.ipynb)
- [Part II — Classical CIFAR-10 classification](./Part_II_Classical_Classification_Task.ipynb)
- [Part III — PyTorch neural-network classification](./Part_III_Neural_Network_Classification_%28PyTorch%29.ipynb)
- [Part IV — PyTorch regression bonus](./Part_IV_Bonus_Task_Neural_Network_Regression_with_Py_Torch.ipynb)

## Reproducibility

The results in the accompanying course report were checked against the notebooks. The final test RMSE reported for the neural-network regression task is 3.0859.
