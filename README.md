## Project Overview
This repository contains the implementation of the final project for the Introduction to Artificial Intelligence course. The project focuses on supervised learning through three distinct tasks, demonstrating modeling choices, evaluation methodology, and practical implementation.

## 📁 Repository Structure
* **Part I: Regression Task** (`Part_1_Auto_MPG_Regression.ipynb`) – Predicts fuel efficiency (MPG) using Linear, Polynomial, and KNN regression models, including a detailed Exploratory Data Analysis (EDA).
* **Part II: Classical Classification Task** (To be added) – Multi-class classification on the CIFAR-10 dataset using Logistic Regression, SVM, and KNN models.
* **Part III: Neural Network Classification** (`Part_3_Neural_Network_Classification.ipynb`) – A PyTorch-based implementation of a neural network classifier, including hyperparameter optimization and architectural design.

All results reported in the accompanying academic report (Overleaf) exactly match the outputs generated by the code in this repository.
